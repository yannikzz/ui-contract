## 背景：一条挂了很久没人去撞的复议条件

ADR-0001 决定 A 把区域契约做成了**进用户生产目录的代码**（`RegionId` 联合类型 + 元数据 + 结构容器），
而不是一份只在文档里存在的约定。它给自己留了退路：

> 若资产层难以适配 React 之外的技术栈，退回 A′（token 只是文档文字，生产代码另写）并承认人肉翻译。

issue #2 把「资产层多技术栈」排在第一项，理由写得很清楚：**这是复议条件，越晚撞代价越大**。
结果 0.3.0 发出去时，第 2、3、4 项都做了，唯独第 1 项一行没写——**风险最高的那一项，
被拖成了唯一没做的那一项**。

## 量到了什么

两个非 React 端口，各自跑真实类型检查（`testing/stack-probes/`，可重跑）：

| | 检查器 | 合法用法 | 白名单外的区域名 |
|---|---|---|---|
| **Vue 3 SFC** | `vue-tsc` | exit 0 | `TS2322: Type '"sidebar"' is not assignable to type 'RegionId'` |
| **React Native** | `tsc` | exit 0 | `TS2322: Type '"sidebar"' is not assignable to type '"app-shell" \| …'` |

`REGION_META` 少一个键，两边都是 `TS2741: Property 'stage' is missing`。

## 决策一：**复议条件不触发，决定 A 不动**

三件机制里前两件是**纯 TypeScript**，与视图层无关；第三件（容器）在两个栈里都能自然表达。
Vue 需要把文件拆成两个（SFC 导不干净类型），这是唯一的结构性改动 —— 那是**适配**，不是硬凑。

**「难以适配」的门槛没有被跨过。** 不退回 A′。

⚠ 这条结论的边界写清楚：量的是 **Vue 与 React Native**，都有 TypeScript。
Svelte 与原生 JS 没量（见下）。**决定 A 在有类型系统的栈上被证实了一次，不是在所有栈上。**

## 决策二：体检的技术栈假设变成配置，而不是继续写死

这是这次真正的产出。资产层跨得了栈，`ui-contract-audit` 跨不了 —— 而且**失效是静默的**。

React Native 端口暴露了三层 DOM 假设，全部实测：

| # | 假设 | 后果 |
|---|---|---|
| 1 | 标记名写死 `data-region` | RN 盖的是 `testID`，检查找不到 → 报绿 |
| 2 | 模式是 `<[a-z]`（「裸元素是小写的」） | RN 里没有小写元素，一个都匹配不到 |
| 3 | 容器文件从未被排除 | React 侥幸过关，因为 JSX 写 `data-region={id}` 用花括号；Vue 写 `:data-region="id"`，**资产层自己被判成违反它自己实现的规则** |

修之前的实测：一个 RN 项目，屏幕里写着 `<View testID="sidebar" />`
（白名单外、不走容器、就是这条检查存在的理由），**检查 1、2、2b 同时报绿**。

**改动**：`SRC_EXT` / `REGION_TYPE` / `REGION_COMPONENT` / `MARKER` 四个旋钮进 `audit.sh` 顶部，
标签匹配改为大小写不敏感，容器文件按路径排除。五条注入用例守着（体检用例 25 → 30）。

## 决策三：标记与平台共用时，**报判不了，不报绿**

第 3 层修不掉，而且不该修：**RN 的 `testID` 不是我们的命名空间**，它本来就是 e2e 钩子。
「容器外出现 testID」是测试的证据，不是绕过的证据，grep 分不开这两件事。

所以加 `MARKER_EXCLUSIVE`。为 `"no"` 时检查 2b 报 **skip 并说明理由**，不打绿勾。

判据是本仓库反复用的那一条：**一条返回貌似合理的错答案的检查，比一条不回答的检查更坏。**
与检查 8 遇到 oklch 时的处理、与 `hue-basis-stated` 被删的处理，是同一条规矩。

**代价明说**：在无独占标记的平台上，「不许绕过容器」这条纪律**只剩评审**。
检查 1 仍然有效（它读的是容器调用点，每个栈都有），所以丢的是「有没有人绕过容器」，
不是「区域名对不对」。

## 排除的方案

| 方案 | 为什么不 |
|---|---|
| 插件里带一张多技术栈映射表（Vue/Svelte/RN/… 各一份模板） | 那是替用户的栈做决定，而且必然过期。资产层进的是**用户的**生产树，跟随他们既有的约定，不是跟随我们的表 |
| RN 上换一个不冲突的标记属性 | RN 的 host 组件不接受任意 props，没有可用的自由命名空间 |
| RN 上照旧判「容器外的 testID 都是绕过」 | 会把每一个 e2e 钩子判成违规。假阳比漏判贵——第一次误报就会被加例外，然后这条检查就死了 |
| 把检查 2b 在 RN 上直接删掉 | 删掉之后没人知道它不在了。skip 会每次跑都把这个缺口打印出来 |

## 仍然没有覆盖的

| | 状态 |
|---|---|
| **Svelte** | 没量。与 Vue 同类（编译期检查 + TS），**预期**通过——那是预期不是测量 |
| **原生 JS** | 没量。这是**声明过的降级**：无类型系统 → 编译期层整个失效，`ui-contract-assets` 要求明说而不是假装装上了 |
| **跨技术栈同名** | **仍然无人验证**。这两个探针验的是**区域名**机制，不是 **token 名**——而后者才是借用 shadcn 命名的唯一理由。issue #6 第 7 笔照旧欠着 |

第三行值得单独说：很容易把这次的结果读成「跨栈这件事验完了」。**没有。**
验完的是决定 A 的复议条件，而 ADR-0005 借命名的理由是另一件事，一个字都没被碰过。

## 复议条件

| 条件 | 怎么处理 |
|---|---|
| 某个有类型系统的栈里，`RegionId` 或结构容器**无法自然表达** | 那才是决定 A 的复议信号。先把那个栈的探针加进 `testing/stack-probes/` 再谈 |
| 原生 JS 项目上，两层强制被证明不够用 | 不是复议决定 A，是复议「无类型系统时是否该接这个活」——可能的结论是前置门直接停 |
| `MARKER_EXCLUSIVE="no"` 的平台越来越多 | 说明「靠属性盖标记」这个形态本身在移动/原生端不成立，要换机制（例如容器在运行时注册到一张表里），而不是继续加旋钮 |

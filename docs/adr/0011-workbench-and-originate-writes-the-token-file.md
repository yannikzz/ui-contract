## 一句话的框架

UI 是**一个东西的两个维度**：`layout.md` 管排版布局，`design.md` 管颜色、圆角、间距。
这两个维度并排放在项目根同一层，本来就是按这个设计的（`layout.md` §0 的标题就是「与视觉规范的分工」）。

这份记录把同一条线画到产物上：

> **两个维度的排练进工作台，不提交；两个维度的权威留在仓库里。**

## 决策一：工作台 `.ui-contract-local/`，不提交

线框现在与 `src/` 平级坐在项目根，还抢了构建工具的 root——它自称一次性，却长得像项目的一部分。

| 排练 → 工作台，不提交 | 权威 → 仓库，提交 |
|---|---|
| 线框（layout 维度） | `layout.md` · `design.md` |
| `tokens.input.json`（design 维度的旋钮记录） | **token 文件**——生产代码读它取每一个值 |
| 皮肤改动 | `docs/ui-contract/`——config 与决策记录 |

**支撑它的论据不是「一次性文件不值得提交」，而是：线框的持久产出从来不是线框本身。**
建它的价值是把规范的洞逼出来，而规矩是先改文档再改代码，所以值钱的东西落在 `layout.md` 里——
那是提交的。线框是产生那个结果的器具，不是结果。

**名字不叫 `.ui-contract/`**：它和提交着的 `docs/ui-contract/` 只差一个前缀，命运却相反，
早晚有人 ignore 错一个。`-local` 是消歧符，读 `.gitignore` 的人不用查文档。

## 决策二：`originate` 自己写 token 文件，中间那一跳去掉

原链路是 `originate` 写 `tokens.input.json` → `ui-contract-assets` 读它、落成 token 文件。

**那一跳是整条链上实测最脆的一环**：五次有效 run 里只落地 **2/5**，而跳过的三次
「在 trace 里提到这个文件 12 次和 8 次——想到了、没写」。

ADR-0009 在上游一格遇到过完全相同的形状（`originate` 依赖一个没装的外部技能，静默失败，
两个分支产出的东西**从外面看都像正常完整的交付物**），它的修法是**去掉那一跳，而不是加一句叮嘱**。
这里沿用同一个判例。

工作台的决定让这一跳更站不住：交接物现在**不提交**了。`design` 今天跑、`assets` 下周在另一台
机器上跑，交接物根本不存在——交接物最不该有的两个性质它同时具备。

于是：

- `originate` Step 2 直接写 **token 文件**（路径与格式来自 `config.md` 的路径表；格式列空着就问）
- `tokens.input.json` 退回成**调校会话的暂存格式**：器具的起始状态，格式中立，调完就是死的
- `ui-contract-assets` **不再读它**，改为消费 token 文件——和生产代码一样

⚠ **`tokens.input.json` 不是产物，是会话内的暂存文件。** 调完之后没有任何东西读它。
它还存在的唯一理由是格式中立：token 文件可能是 CSS 自定义属性、`theme.extend` 或主题对象，
而器具是一个通用 HTML 页面，解析不了每一种。别让任何人以为它需要被保留或维护。

落点同时改到 `.ui-contract-local/tokens.input.json`，**钉死照旧，理由换掉**：
原来是「下游要一个答案」，而下游刚被删掉；现在是「器具和判据都要一个确定路径」
（`regex` 判据的 `target.path` 不是 glob）。

## 决策三：决定 B 的复议条件改写

ADR-0001 决定 B 挂着「若实测生成品牌被用户推翻的比例过高」，而 `originate.md` 明写
`tokens.input.json` 的 v1↔调后 diff 是那个数字**唯一的来源**。文件不提交，就没有版本可 diff。

**不留着它。** 留着等于在 ADR-0001 里放一条指向永远不存在之物的复议条件——读起来完全正常，
没有任何东西会发现。这正是本仓库反复吃亏的形状。

改写而不是补数据，理由有三条，都是查出来的：

1. **没有任何东西在计算那个 diff。** 三个 eval 用例的 grader 目录里，`diff` 只出现在
   `tokens-input-written` 的说明文字里，解释这个文件为什么重要——不是一条会跑的检查。
2. **数据本来就是脏的。** ADR-0007 自己记着：「拧了个旋钮」→「JSON 变了」中间隔着一个 agent，
   那个 diff **分不出用户的选择和 agent 的误读**。
3. 它是一个跨项目统计，而插件没有遥测，没有汇总机制。

**决定 B 的复议条件改为**：若 `originate` 派生出的值在实跑中系统性落在框架默认色上，
说明坐标没有走到值，这个能力不成立——这一条**已经有判据在跑**
（`no-framework-default-values`），不需要新造测量。

## 排除的方案

| 方案 | 为什么不 |
|---|---|
| **把 token 值放进模板** | 带值的模板就是一套默认品牌，违反 ADR-0001 原则 3。ADR-0009 已经指认了入口：三条轴管颜色的数量与饱和度，**没有一条管色相**，模板会把那个空格子永久填成同一个值 |
| **保留两跳，要求 `design` 跑完当场落地** | 「当场」是一句纪律，而纪律正是这条链上已经失败过 3/5 次的东西 |
| **工作台仍然提交，只是换个隐藏目录** | 拿不到「一次性产物不冒充项目一部分」以外的收益，且 `tokens.input.json` 会继续以交接物的身份存在 |
| **`tokens.input.json` 整个删掉** | 器具就没有旋钮可拧了。它的格式中立是真实需求，不是历史包袱 |
| **让 `assets` 继续读它，只是改路径** | 读一个不提交的本地文件来重建值权威——clone 之后那个文件不存在 |

## 代价，写下来而不是藏着

- **CI 里能跑的守卫少了一层。** 白名单的编译期校验原来挂在线框的 typecheck 上，线框不进仓库，
  这层就不在 CI 里。**这条已经先行处理**：`ui-contract-enforce` 新增「编译期层必须坐在会发布的
  代码上」一节，`ui-contract-assets` 认领了禁令型的类型，`constraint-by-types` §2 加了自断言文件。
  **顺序不能反**——先搬走线框再搬强制机制，中间会有一段守卫真空期。
- **新克隆拿不到线框。** 「给 coding agent 的可运行参照」这句话此后只对本机成立，
  所有产物里都必须加限定词并写明重建路径。
- **两条 eval 判据指向了一个没有实跑样本的新落点。** 判据同步改了，但
  `tokens-input-at-pinned-path` 此前的正方向结清验的是**旧落点**。新落点一次实跑都没跑过。
- **`no-framework-default-values` 从此看的不是值的权威。** 它读旋钮记录，而权威是 token 文件。
  两者由同一步、同一批派生值写出，所以现在等价；将来若会分叉，这条判据就在看错的文件。
  换到 token 文件也不行——那个文件格式是项目相关的，而 `regex` 判据要一个确定路径。
- **`originate` 现在往生产树里写一个文件**，跨了「谁写生产代码」那条包边界。接受，
  因为另一头是一个 3/5 会丢的交接物。

## 复议条件

| 条件 | 动作 |
|---|---|
| 若实测显示 `originate` 写 token 文件的落地率也低于交接物 | 说明问题不在跳数，重新审视 Step 2 的完成判据 |
| 若某个项目确实需要跨机器、跨时间地传递旋钮状态 | 那时 `tokens.input.json` 需要重新变成一个提交的产物，本记录的决策二要重判 |
| 若「编译期强制搬到产品源码」在实跑中没有落地 | 工作台这个决定的净效果为负，应当退回到线框提交 |

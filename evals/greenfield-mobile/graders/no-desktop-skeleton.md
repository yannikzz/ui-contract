# 不把桌面端骨架套到手机上

产出中**不得出现**为桌面形态设计的结构词汇，除非是在明确否定它们：

- 三栏 / 三列 / three-column
- 侧边栏 sidebar 作为常驻导航
- 「聚焦槽」「属性面板」作为一个常驻的第二列

手机形态的正确等价物是**下钻一层**或**底部抽屉**，导航是底部标签栏 / 抽屉 / 页面栈。若是页面栈，区域树必须是**一屏一棵**，不是一棵大树。

**判定**：出现上述任一桌面词汇且不是在说明「本形态不适用」→ 不通过。

`originate` 派生出来的值必须**落成文件**，不能只在 `design.md` 里被描述。

这条判据是从一次实测里长出来的，不是设计出来的：五次有效 with run 里 `design.md` 落地 5/5，
而 `tokens.input.json` 只有 2/5——跳过的那几次在 trace 里提到这个文件 12 次和 8 次，
想到了、没写。

它不是可有可无的文件。ADR-0001 决定 B 的复议条件挂在「用户覆盖生成品牌的比例」上，
而 `originate.md` 明写这份文件的 v1 与用户调完之后的版本之间那个 diff 是那个数字**唯一的来源**。
40% 的落地率等于那条复议条件六成时间没有数据。

⚠ **加上这条，这个用例的满分会从 1.00 掉到 0.75，直到产品那边的修复生效。**
那是**真红**，不是判据太严——缺口是量出来的。同一次测量还给出了修复方向：进了

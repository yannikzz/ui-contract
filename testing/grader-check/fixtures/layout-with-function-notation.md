# 运营后台视觉规范

## 1. 色彩
主色 `oklch(0.38 0.100 331)`，hover 态 `oklch(0.30 0.100 304)`。卡片面 `oklch(1.00 0.100 360)`，页面底 `oklch(0.98 0.100 355)`，描边 `oklch(0.91 0.100 338)`。
状态色：成功 `oklch(0.50 0.100 104)`、警告 `oklch(0.52 0.100 8)`、错误 `oklch(0.30 0.100 53)`。状态色只用于小标签和状态点。

## 2. 字号
12 / 13 / 14 / 16 / 20，四级文字层级，不再加第五级。

## 3. 圆角与阴影
小元件 4px，卡片 6px，弹层 10px。阴影只有一档。

## 4. 布局骨架
左侧导航固定 220px 宽，收起后 56px。主区最小可用宽 640px，低于这个宽度导航先收。
右侧属性面板 360px，固定不可拖拽。
列表页结构：顶部一条筛选条，下面是表格，点行在右侧开属性面板。

## 5. 按钮
主按钮实心主色，次按钮描边，幽灵按钮无边框。三级，不再加。

## 6. 表格
行高 40px，斑马纹关闭，hover 行底色 `oklch(0.98 0.100 355)`。

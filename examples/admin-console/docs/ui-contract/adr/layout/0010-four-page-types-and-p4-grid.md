## 背景

设计稿只覆盖两种页面：列表页（P1）与向导页（P2）。但导航里的「系统」组必然需要设置表单页，「工作台」必然需要概览页。规范要能给「新页面该长什么样」一个答案，就不能只写有图的那两种。

P4 概览页尤其没有依据：卡片怎么排、能占多宽，图上一个字都没有。

## 决策

定四种页型：列表页 P1 / 向导页 P2 / 设置表单页 P3 / 概览页 P4。P4 用 12 列网格，卡片只能占 3 / 4 / 6 / 12 格。

## 排除的备选

**只写有设计稿的 P1 和 P2，P3 / P4 等有图再补。** 它换来的是规范里没有任何编造成分。排除的理由是缺口不会等着被填——在 P3 / P4 有图之前，一定会有人先去做「系统」组的配置页和工作台。规范对这两种页面沉默，结果不是「大家等着」，而是**每个 Agent 各自发明一套**，等设计稿来的时候已经有三种互不兼容的实现了。

**P4 的自由网格（卡片想多宽就多宽）也被排除**：自由宽度下每张新卡片都会挑一个看起来合适的宽度，半年后概览页是一堆对不齐的矩形。限定 3 / 4 / 6 / 12 四档是为了让 Agent **有据可依**，不是因为知道这个产品的工作台长什么样。

## 明知接受的代价

- P3 与 P4 的规范内容**是推断，不是从图上量出来的**，这是它们与 P1 / P2 的本质区别
- 12 列网格与四档卡片宽度是一个**约定**，不是从任何需求推出来的结论

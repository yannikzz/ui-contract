## 为什么是灰的

线框刻意不含品牌视觉。带品牌视觉的骨架会变成第二个视觉权威源：`design.md` 一改，这里就成了过期规范，而 Agent 更信眼前的代码。所以这里只有中性灰阶 + 系统字体，状态标签统一一个灰色，按钮只用灰阶深浅表达层级。

**要看的是结构和密度，不是颜色。**

## 控制 → 验什么

右侧控制面板不属于产品界面，是给你验收用的。它在视口（浅灰圆角那块）外面；只放作用在原型上的控制，按「选屏 / 条件 / 视图 / 输出」四区排，顺序由面板定。作用在视口上的（镜头缩放、适应窗口、画布底色）在视口右下角。

> **样张墙没有接入。** 外壳还内联在 `App.tsx` 里带着 hooks，铺不成样张，所以左下角没有视图切换。这是落后，不是取舍，记在 `examples/README.md` 的落后表里。

| 开关 | 验什么 | 该看到什么 |
|---|---|---|
| **页型：P1 列表页** | 主场景。筛选条 + 表格 + 属性面板 | **初始面板是关闭的**（主区全宽）——点任意一行才滑出。打开后它在文档流内**挤窄**表格（不是盖住），筛选条跟着变窄 |
| 勾选几行的复选框 | `main.bulkbar` 在没有选中时**整个不渲染** | 勾第一行时批量条出现，取消全部勾选后它消失（不是变灰） |
| **页型：P2 向导页** | `layout.md` §4.2 矩阵：向导页**没有属性面板、没有筛选条** | 右侧空无一物。这是硬禁止，不是没做 |
| **页型：P3 设置表单页** | P1 与 P3 语义不同（§4.1 对照表） | 有底部保存区，没有分页，没有面板 |
| **页型：P4 概览页** | 12 列网格 + 卡片占 3/4/6/12 格 | 4 张小卡一行 + 2 张半宽卡 + 2 张半宽列表卡；**没有筛选条** |
| **窗口宽：1440 / 1180 / 1024 / 900 / 680** | 降级链（§3.4）。**这是最需要你验的一项** | 1440 不降级；**1180** 导航自动收成图标条（角标还在）；**1024** 面板从「挤窄」变「覆盖」，表格恢复全宽；900 维持覆盖态；**680** 触底，主区停在 640，表格横向滚动，标识列与选择框**不跟着滚走** |
| | 底部数字行同时给出算式依据 | 640 阈值的算法：可用宽 = 外壳宽 − 导航宽 − （面板挤窄时的 360）。所以 W<1220 触发级 1、W<1056 触发级 2、W<696 触底 |
| **导航偏好：open / closed** | 手动优先且双向生效（§3.4） | 选 `open` 后即使窄屏也不自动收；选 `closed` 后即使宽屏也保持图标条 |
| **列表状态：空 / 筛选后空** | 两种空态动作不同（§8.1） | 「空」的动作是「批量导入」，「筛选后空」的动作是「清除全部条件」 |
| **列表状态：加载** | 表头保留可见，只有行区在加载；禁止整区骨架屏 | 表头先在，下面是加载态 |
| **列表状态：局部失败** | 出错的那一行原地标出，其它行照常可用 | 第 4 行状态显示「未知」+ 一行说明 |
| **列表状态：整区失败** | 筛选条仍然可用 | 表格区一句原因 + 重试 |
| **面板状态：加载 / 整区失败** | 先点一行把面板打开，这两个开关才看得到效果 | — |
| **面板状态：加载** | `inspector.head` 的对象标识**先出** | 面板头部有标题，主体在加载 |
| **面板状态：整区失败** | **禁止自动关闭面板**（§8.1） | 面板还在，里面是失败说明 + 重试 |
| **向导步：第 1/2/3 步** | 预检失败留在当前步内、「下一步」禁用（§8.1） | 第 2 步有 2 行无法导入 → 下一步是禁用的，且**没有用 toast** |
| **覆盖层** | §4.5：盖住 stage 全部但**不盖导航**、自带头部、Esc 关闭、禁止叠层 | 左侧导航仍可点；覆盖层顶部有自己的标题和关闭 |
| **区域标注** | 白名单的第三种形态 | 每个区域左上角有中文模块名，**hover 角标**会浮出 `data-region` 代码名 + 「该放什么/不该放什么」 |
| 面板顶部的读数块 | 降级规则可以**对着数字验**，不靠感觉 | 外壳实测宽 / 显示比例 / 导航宽 / 面板模式 / 主区宽 / 阈值 640 / 触发了哪几级降级 |
| 右下角 − / % / + / 适应，或触控板捏合、⌘+滚轮 | 镜头改的是显示比例，**不是实测宽** | 缩放时读数块里「显示比例」变，「外壳实测」不变 |

## 重点验这几处（我看不到渲染结果）

我没有能看网页的工具，所以下面这些**我验不了**，请你打开看：

1. **面板打开后，6 个筛选控件是否换行成两行？** 换行了是不是还能接受？（不能接受就要减控件或改成收纳式，那是一次 `layout.md` 变更）
2. **超长中文标题在 300 宽的标识列里截断得对不对？** 特别是「2026 年第三季度城市轨道交通运营数据月报（含 12 城对比与同比口径说明）」这一行。
3. **窗口拖到 1024 附近，降级有没有抖动**（反复收/展）。
4. **触底后横向滚动时，标识列 sticky 有没有出现背景穿透**（滚动内容从半透明选中行底下透出来）。
5. **属性面板里 9 个字段 + 5 个操作按钮，360 宽够不够**，操作按钮会不会挤成三行。
6. 概览页 8 张卡在 1440 宽下的观感。

## 目录

```
admin-console/                 项目根：依赖、构建配置、两份规范都在这里
├── package.json · tsconfig.json · vite.config.ts · check-colours.sh
├── layout.md · design.md
├── src/                       生产代码。**重建线框碰不到这里**
│   ├── tokens.css             token 文件：值的权威
│   ├── ui/region.tsx          资产层：RegionId + 四条禁令类型 + 元信息 + 结构容器
│   └── ui-contract.assert.ts  禁令自断言：删掉禁令会让 tsc 报 TS2578
└── .ui-contract-local/        工作台。**真实项目不提交；本示例刻意提交**
    └── wireframe/             ← 本目录。一次性，结构变了整个重新生成
        ├── CLAUDE.md          目录级硬约束 + 刻意的取舍清单（改代码前必读）
        ├── README.md          本文件
        ├── index.html
        └── src/
            ├── inspect.tsx    装置：区域标注层 + 浏览器外观（页框/视口/角落/面板/区/墙）。**颜色豁免就是这个文件**
            ├── wire.tsx       中性零件 + NEUTRAL 色板（唯一允许写颜色值的另一处）
            ├── structure.ts   结构参数（STRUCT）+ 降级判定纯函数（resolveShell）
            ├── fixtures.ts    假数据（**不是规格**）
            ├── Inspector.tsx  聚焦槽（属性面板）
            ├── App.tsx        浏览器状态 + 外壳组合 + 降级实算（自己不带颜色，也不决定控件放哪）
            └── pages/         每种页型一个文件
```

`src/` 整个住在这个目录之外，是刻意的：线框自称一次性、结构变了重新生成，
而白名单、四条禁令类型、自断言和 token 文件**都不能跟着一起被重新生成掉**——
它们约束的是会发布的代码。`vite.config.ts` 把 root 设成 `.ui-contract-local/wireframe`，
但依赖与类型检查是整个项目的。
